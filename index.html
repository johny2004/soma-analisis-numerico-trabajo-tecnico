Sobre el método. En cada intervalo, la spline se escribe como Sⱼ(x) = aⱼ + bⱼ(x − xⱼ) + cⱼ(x − xⱼ)² + dⱼ(x − xⱼ)³. Para la condición natural, c₀ = cₙ = 0; los cⱼ internos se obtienen del sistema tridiagonal hⱼ₋₁cⱼ₋₁ + 2(hⱼ₋₁ + hⱼ)cⱼ + hⱼcⱼ₊₁ = 3[(aⱼ₊₁ − aⱼ)/hⱼ − (aⱼ − aⱼ₋₁)/hⱼ₋₁]. Luego se calculan bⱼ y dⱼ con las fórmulas de la hoja. PCHIP se muestra como comparación. La banda se estima con 100 simulaciones Monte Carlo (σ = 2.5 µg/m³). La validación corresponde a los 8 nodos internos.
